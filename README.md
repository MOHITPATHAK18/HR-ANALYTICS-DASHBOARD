## 📌 Project Overview

The **HR Analytics Dashboard (Excel)** provides a structured analysis of employee data to uncover insights into **attrition, workforce demographics, and organizational trends**. Built using advanced Excel features, this dashboard enables **data-driven HR decision-making**.

---

## 🎯 Objectives

* Analyze employee attrition and retention patterns
* Monitor workforce distribution across departments and roles
* Track key HR metrics and performance indicators
* Provide actionable insights using Excel-based visualizations

---

## 📈 Key Features

* 📊 Interactive dashboard using Pivot Tables and Charts
* 📌 KPI tracking (Total Employees, Attrition Rate, Active Employees)
* 👥 Employee segmentation by age, gender, and department
* 📉 Attrition analysis across roles and experience levels
* 🎯 Dynamic filtering using slicers
